# debracket — 矯正装置の自動除去＋手動補修

矯正装置（ブラケット・ワイヤー・バンド）が付いたままの口腔内スキャンSTLから、
装置を自動検出・除去し、歯面を曲率連続で復元する。うまくいかない箇所は
同梱の3Dビューアで囲って削り、自動で埋め直す補修ルートがある。

## パッケージ構成（このスキルの前提レイアウト）

```
debracket_skill_v1.0/
├── README.md              ← 人間向けの導入手順
├── 補修手順ガイド.pdf      ← スライド形式の補修マニュアル（スクショ付き）
├── claude/SKILL.md        ← このファイル
├── codex/AGENTS.md        ← Codex CLI 用の同内容
├── bin/debracket_ml.py    ← 本体（実行エントリ）
├── bin/debracket.py       ← 幾何検出＋MeshLib充填エンジン
├── bin/debracket_train.py ← モデル定義（PointNet++）※推論時に読み込まれる
├── model/best_model.pth   ← 学習済み重み（5.4MB）
└── viewer/                ← PenClaw 3D Viewer（補修用・オフライン動作）
```

パスは自動解決される（bin/ から ../model と ../viewer を探す）。フォルダ構成を
崩さないこと。

## セットアップ（初回のみ）

Python 3.10以上で:

```bash
python3 -m pip install --user torch numpy trimesh scipy meshlib
```

macOS/Linux/Windows いずれも可。GPU不要（CPUで1顎2〜5分）。

## 基本の使い方（1コマンド）

```bash
python3 bin/debracket_ml.py 入力スキャン.stl 出力フォルダ
```

出力: `〜_debracketed.stl`（完成モデル）／`〜_mlmask.npy`（検出マスク）／
`〜_stats.json`（統計）。

### オプション

| オプション | 意味 |
|---|---|
| `--thr 0.4` | ML検出のしきい値（下げると取り漏らし減・削りすぎ増） |
| `--tta 8` | 回転投票の回数（既定8。1で高速・低精度） |
| `--no-hybrid` | 幾何検出との併用をやめML単独にする（通常は使わない） |
| `--detect-only` | 除去せず検出マスクだけ出す（確認用） |
| `--edit-pre` | 処理前にビューアで手動トリム（付着物が多いスキャン向け） |
| `--edit-post` | 処理後にビューアで補修→自動穴埋めまで対話的に実施 |
| `--refill 編集済.stl` | 単独モード: ビューアで削ったSTLの穴埋めだけ実行 |

## 出力の確認ポイント（毎回必須）

1. 完成STLをビューアで開く
2. **左右の最後方臼歯の頬側・遠心面**を見る——スキャン端は自動検出の既知の
   弱点で、バンド・チューブの取り残しが出やすい
3. 充填パッチ（ブラケットがあった場所）の形態が不自然に平坦・膨隆していないか

問題がなければ完成。あれば下の補修手順へ。

## 補修手順（詳細は 補修手順ガイド.pdf）

1. ビューア起動: `viewer/ビューア起動.command` をダブルクリック
   （またはターミナルで `cd viewer && python3 -m http.server 8000` →
   ブラウザで http://localhost:8000/index.html ）
2. 補修したいSTLを画面にドラッグ
3. **ラボ機能を解放**: キーボードで ↑↑↓↓←→←→BA（コナミコマンド）。
   スペック判定で弾かれたら10秒以内にもう一度入力すると強制解放
4. 上部ツールバー「🪢範囲選択」→ 取り残し装置をなげなわで囲む
   → **選択面が赤く表示される（まだ削除されない）**
5. 視点を回しながら「＋追加/−除外」で選択を整える（Shift=一時追加・
   Option=一時除外）。「見える面のみ」ONなら画面に見えている面だけが対象
6. 「削除実行」で確定（1段Undo可）
7. 「STL書き出し」でダウンロード
8. 穴埋め: `python3 bin/debracket_ml.py dummy 出力フォルダ --refill ダウンロードしたファイル.stl`
   → `〜_refilled.stl` が完成品。**穴は外周（スキャンの縁）以外すべて自動充填**される

⚠️ ビューア内の「穴埋め」ボタンは使わない（簡易充填で品質が落ちる）。
削るだけ削って書き出し、充填は必ず --refill（Medit同等の曲率連続充填）で行う。

## 性能の目安（開発時実測）

検出精度 val Dice 0.93級（全頂点・回転投票込み）。健全歯面の保存性は
p99=0.000mm（非除去領域は変形しない）。充填パッチの術者手動除去との一致は
RMS 0.15〜0.30mm。数値は開発データでの参考値であり、臨床での性能を示すものではない。

## トラブルシュート

| 症状 | 対処 |
|---|---|
| ModuleNotFoundError | セットアップのpipコマンドを再実行（使うpython3が同じか確認） |
| 処理が10分以上終わらない | Ctrl+Cで中断し `--tta 1` で試す |
| 穴が埋まらない | --refill を使ったか確認（ビューアの穴埋めボタンは使わない） |
| ビューアが真っ白 | file://で開いている→必ず http.server 経由で開く |
| ラボが出ない | コナミコマンド再入力（10秒以内2回で強制解放） |
| 削除したら裏側まで消えた | 「見える面のみ」チェックがONか確認 |
| 検出が明らかに変 | 学習データ外の装置種（舌側矯正等）の可能性。--detect-only で確認し手動補修主体で |

## エージェント向けの作法

- ユーザーがSTLパスを渡してきたら基本コマンドを実行し、stats.jsonの要点
  （mask_pct・n_regions）を報告する
- 「穴埋めして」「refill」と編集済みSTLのパスが来たら --refill を実行し、
  出力パスを返す
- 補修のやり方を聞かれたら本書の補修手順と 補修手順ガイド.pdf を案内する
- 患者氏名がファイル名・フォルダ名に含まれる場合は、処理前にリネームを促す
