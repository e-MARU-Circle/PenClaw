# リサーチ・調査コンパイルスキル

特定トピックについて多角的に調査し、簡潔で実用的なレポートにまとめるスキル。

## ワークフロー

1. **調査対象の明確化**
   - トピック・対象を確認
   - 調査の目的（意思決定、学習、プレゼン準備等）
   - 深さ（概要レベル / 詳細分析）
   - 出力フォーマットの希望

2. **情報収集**
   - Web検索で最新情報を収集
   - 接続されたMCP（Notion、Google Drive等）から社内情報を検索
   - 複数のソースからクロスチェック
   - データ・数字は出典を明記

3. **レポート構成**

```
# [トピック] 調査レポート
作成日: [日付]
調査目的: [目的]

## エグゼクティブサマリー（3行以内）
[結論ファーストで最重要ポイントをまとめる]

## 背景・現状
[トピックの基本情報と現在の状況]

## 主要な発見（3-5項目）
### 1. [発見1]
- 詳細
- データ/根拠
- 出典

### 2. [発見2]
...

## 分析・考察
[発見から導かれる示唆、トレンド、リスク]

## 推奨アクション
1. [具体的なアクション1]
2. [具体的なアクション2]
3. [具体的なアクション3]

## 出典・参考リンク
- [ソース1](URL)
- [ソース2](URL)
```

4. **出力**
   - マークダウンファイルとして保存
   - 必要に応じてWord/PDFでも出力可能
   - スライド用のサマリーも要望があれば作成

## 調査タイプ別のガイド

### 企業・競合調査
- 事業概要、売上/従業員数、最近のニュース、経営陣、競合との比較

### 技術調査
- 技術概要、メリット/デメリット、採用事例、エコシステム、将来性

### 市場調査
- 市場規模、成長率、主要プレイヤー、トレンド、参入障壁

## 注意事項
- 事実と意見を明確に区別する
- 情報の鮮度を意識し、古いデータには注記を入れる
- 見つからない情報は「情報なし」と正直に記載する
- ユーザーの業務コンテキスト（about-me.md、current-projects.md）があれば参照し、関連性の高い情報を優先する
