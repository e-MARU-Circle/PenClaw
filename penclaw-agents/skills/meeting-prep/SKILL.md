# ミーティング準備スキル

会議前に必要な情報を収集し、構造化されたブリーフィング資料を作成するスキル。

## ワークフロー

1. **情報収集**: ユーザーから以下を確認する
   - 会議の相手（名前・会社・役職）
   - 会議の目的・アジェンダ
   - 会議の日時・形式（オンライン/対面）
   - 過去のやり取りや背景情報があれば確認

2. **リサーチ実行**: 利用可能なツールで以下を調査
   - 相手の会社情報（事業内容、最近のニュース、プレスリリース）
   - 相手のプロフィール（LinkedIn、公開情報）
   - 業界の最新動向
   - 過去のメール・チャット履歴（MCPで接続されている場合）

3. **ブリーフィング資料を作成**: 以下の構成で1ページにまとめる

```
# ミーティングブリーフ: [相手名] @ [会社名]
日時: [日時]
形式: [オンライン/対面]

## 相手について
- [会社概要・最近の動き]
- [相手のプロフィール・役割]

## 会議の目的
- [アジェンダ・ゴール]

## トーキングポイント（3つ）
1. [ポイント1 + 背景]
2. [ポイント2 + 背景]
3. [ポイント3 + 背景]

## 想定される質問と回答
- Q: [想定質問1]
  A: [回答案]
- Q: [想定質問2]
  A: [回答案]

## ネクストアクション候補
- [会議後に取るべきアクション案]
```

4. **出力**: マークダウンファイルとして保存。必要に応じてWord/PDF形式でも出力可能。

## 注意事項
- リサーチは利用可能なツール（Web検索、MCP接続先）の範囲内で行う
- 見つからない情報は正直に「情報なし」と記載する。推測で埋めない
- 社内ミーティング（1on1、チームMTG）の場合は外部リサーチを省略し、アジェンダ整理とトーキングポイントに注力する
- ユーザーのコミュニケーションスタイル（about-me.mdがあれば参照）に合わせて出力する
