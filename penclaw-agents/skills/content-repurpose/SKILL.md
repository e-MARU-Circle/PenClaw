# コンテンツ転用スキル

1つの元コンテンツから、複数のプラットフォームに最適化されたコンテンツを生成するスキル。

## ワークフロー

1. **元コンテンツの取得**
   - URL、ファイル、テキストなど、元コンテンツを受け取る
   - 動画/音声の場合はテキスト起こしから開始
   - 元コンテンツの核となるメッセージ・要点を抽出する

2. **ユーザーに確認**
   - 出力したいプラットフォーム（Twitter/X、LinkedIn、ニュースレター、ブログ等）
   - ブランドボイス（brand-voice.mdがあれば参照）
   - 特に強調したいポイントがあるか
   - トーンの方向性（教育的、刺激的、カジュアル等）

3. **プラットフォーム別に変換**

### Twitter/X（5投稿）
- 1投稿あたり280文字以内（日本語なら140文字が目安）
- フック → 本題 → CTA の構成
- ハッシュタグは1-2個まで
- スレッド形式も選択可能

### LinkedIn（1投稿）
- 500-1500文字
- ストーリーテリング形式
- 冒頭3行でフックを作る（「続きを読む」前に読ませる）
- プロフェッショナルなトーン

### ニュースレター（1ドラフト）
- 件名 + プレビューテキスト
- 導入 → 本題（3-5セクション）→ CTA
- 読了時間3-5分を目標

### ブログ記事（1記事）
- SEOを意識したタイトルと見出し構成
- 1500-3000文字
- 内部リンク・外部リンクの提案

### ショート動画アイデア（5-10案）
- 各15-60秒のスクリプト
- フック（最初の3秒）を明記
- 元コンテンツからのタイムスタンプ（動画の場合）

4. **出力**
   - 全コンテンツをまとめたマークダウンファイルとして保存
   - プラットフォーム別にセクション分け
   - Google Driveへの保存が可能な場合は自動保存

## 注意事項
- 各プラットフォームの文字数制限・フォーマットルールを厳守する
- 単なるコピペではなく、各プラットフォームのネイティブな表現に合わせる
- brand-voice.mdがあれば必ず参照し、トーンを統一する
- 出力後に「調整したいものはありますか？」と確認する
