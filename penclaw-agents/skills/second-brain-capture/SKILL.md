# Second Brain 転記スキル

## 振り分けルール

1. **外部記憶DB**: セミナー・ウェビナー・業者打ち合わせ・書籍/記事・動画/音声のまとめ。プロパティ: タイトル / 種別 / 日付 / 分野 / 講師・相手 / 要点（3行以内）/ 自分への示唆 / ソースURL / 取り込み元 / 整理状態=「受信箱」。詳細は行の本文へ。
2. **内省ログ**: 先生の内面・心情・気づきの発言。**要約・評価・添削禁止、発言をそのまま記録**。プロパティ: 見出し / 日付 / 天気 / 感情タグ / テーマ / 気づき。
3. **ビジョンDB**: 将来の方向性の言語化。**既存行を上書きせず新規行を追加**（旧行の状態変更は先生の承認後のみ）。プロパティ: ビジョン / ホライズン（いま・1年・3年・10年・人生）/ 状態=構想 / 宣言日=言語化した日 / 領域 / ステートメント。

## 朝ブリーフィングでの自動転記

朝ブリ実行時、内容に以下が含まれたら該当DBへ自動転記する（先生への確認不要、報告のみ）:

- 前日〜当日のセミナー/ウェビナー/業者打ち合わせのまとめ → 外部記憶DB（取り込み元=朝ブリ）
- 先生の内省・心情に関わる発言の引用 → 内省ログ
- ビジョン・将来方向の新しい言語化 → ビジョンDB（新規行）

転記後、朝ブリ末尾に「🧠 Second Brainに N件転記」と1行報告。

## 転記しないもの

- KPI・未読メール・タスク等の日次情報（Live Dashboardの領分）
- AI向けの技術知識・決定事項（ローカル knowledge_base/ と memory/ の領分）

## 重複防止

同一ソース・同一日の既存行があれば新規作成せず、その行の本文に追記する。
